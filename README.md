# Cyber Command Center

Create a sophisticated, enterprise-grade cybersecurity portfolio website. The design should feel premium, minimalist, and advanced—resembling a high-end security command center.

Design Language:

Aesthetic: Use 'Glassmorphism' (semi-transparent backgrounds with blur effects) and a refined color palette: Deep navy/charcoal for dark mode and crisp slate-gray/white for light mode.

Toggle: A smooth, animated light/dark mode switcher in the top-right corner.

Typography: Use a clean, modern sans-serif typeface (like Inter) for body text and a crisp monospaced font (like JetBrains Mono) for headings and technical tags to emphasize the coding/security background.

Motion: Subtle, elegant animations (faded entrance effects, smooth hover transitions on cards).

Section Structure:

Hero: A high-end split-screen layout. Left side: Professional portrait placeholder with a subtle glow or border effect. Right side: Minimalist, high-impact headline and a refined 'Terminal-style' bio snippet.

Expertise & Stack: Use a 'bento-grid' layout for skills, showing mastery of SIEM, Penetration Testing, and AI-Security. Highlight Google AI Essentials with a special 'Verified' badge design.

Project Dashboard: Instead of simple cards, design the projects section as a 'Live Monitor' grid, showing project status, technology tags, and 'View Analysis' buttons.

Certifications: A sleek, horizontal timeline or carousel that treats each certification as a distinct, prestigious credential.

Contact: An integrated, minimalist form that looks like a secure terminal command input.

Ensure the site is fully responsive, high-performance, and visually polished for a recruiter at a top-tier firm.
